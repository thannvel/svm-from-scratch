# svm-from-scratch
# Overview
This project presents a complete implementation of a Support Vector Machine developed entirely from scratch using Python and NumPy. A synthetic dataset generated with Scikit-learn is used to train and evaluate the model, while Matplotlib is employed to visualize the decision boundary and margin lines.

# Objective
The primary objective of this project is to develop a linear SVM classifier from first principles and gain a practical understanding of the optimization process that drives maximum-margin classification.

# Technologies Used
- Python 3
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

# Results
The custom implementation successfully learns a linear decision boundary that separates the two classes of the synthetic dataset. After training, the classifier achieves high classification accuracy on the testing set.
